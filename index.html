Features

Everything an IDE needs.
Nothing to set up.

nvim and emacs make you build your editor from scratch. Toast ships with the parts that matter, so you can start editing the moment it opens.

LSP installs missing servers for you

Managed language servers

Toast offers to install the language server you need — gopls, rust-analyzer, pyright, typescript-language-server, harper — using the toolchain you already have. Accept the prompt, keep coding. Servers on your $PATH are picked up automatically.

Config

Remappable everything

Keybindings, LSP servers, tabs, sidebar, and themes — all in one small JSON file at ~/.config/toast/config.json.

config ~/.config/toast/config.json
{  "theme": "toast-dark",
  "keybindings": { "save": ["ctrl+s"] },
  "lsp": { "zig": { "command": "zls" } }
}
Keyboard

Fast by default.

Keyboard-first, mouse-friendly. The chords you need most are one keystroke away — no plugin hunting.

Ctrl+P
Quick open — fuzzy-find any file in the project
Ctrl+Shift+F
Search — ripgrep across the whole tree
Ctrl+Shift+M
Markdown preview — render next to your code
Ctrl+B
Toggle sidebar — the file tree, on demand
Ctrl+G
Go to line — jump anywhere in the buffer
Ctrl+W
Close tab — with a clean unsaved-check

Every binding is remappable — or unbind it entirely — in config.json. See the full list on GitHub.

Install

One command to install.

No Electron download, no dependency tree. A single ~28 MB binary that opens a working IDE.

# macOS & Linux (formula auto-updated on every release)
$ brew install paradise-runner/tap/toast
# macOS (Apple Silicon) — also: toast-darwin-amd64.zip, toast-linux-amd64.zip
$ curl -Lo toast.zip https://github.com/paradise-runner/toast/releases/latest/download/toast-darwin-arm64.zip
$ unzip toast.zip
$ install -m755 toast-darwin-arm64 /usr/local/bin/toast
# requires Go 1.25+; binary lands in bin/toast
$ git clone https://github.com/paradise-runner/toast
$ cd toast
$ make build
Then point it at anything — a directory, a file, or nothing at all. Toast auto-detects the git root.
$ toast $ toast path/to/dir $ toast path/to/file
