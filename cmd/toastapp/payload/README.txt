This directory holds the payload binaries embedded by cmd/toastapp.

The files are generated by scripts/build-libghostty-bundle.sh:

    payload/ghostling            - Ghostling terminal (libghostty-vt + Raylib)
    payload/toast                - the built toast TUI binary
    payload/libghostty-vt.dylib  - shared terminal emulation library

None of them are committed; build the bundle with:

    scripts/build-libghostty-bundle.sh
